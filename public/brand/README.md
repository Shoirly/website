# Shoirly logo

The "o" is a verification seal: the brand in one glance.

## Files
- `logo.svg`: primary wordmark, dark ink on light backgrounds
- `logo-white.svg`: wordmark for dark backgrounds
- `mark.svg`: seal on its own, simplified for small sizes (favicon, app icon, social avatar)
- PNG exports of each, plus light and dark previews

All lettering is outlined, so no font needs to be installed.

## Colours
- Ink: `#0F1B17`
- Seal blue: `#3157F0`
- White: `#FFFFFF`

## Type
Wordmark is drawn from Bricolage Grotesque (weight 720, optical size 96), licensed under the SIL Open Font License. Use the same family for headings if you want the site to match the logo.

## Rules
- Use `mark.svg` below roughly 48px tall; the full wordmark's seal detail is too fine at that size.
- Keep clear space around the logo of at least the height of the seal.
- Don't recolour the seal, stretch the logo, or add effects.
